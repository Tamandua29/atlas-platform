# Architecture Decision Records

Os ADRs registram decisões arquitetônicas relevantes do Atlas Platform.

## Convenção

- nome: `NNNN-titulo-curto.md`;
- status: Proposto, Aceito, Substituído ou Rejeitado;
- uma decisão por arquivo;
- alterações posteriores não apagam o histórico: um novo ADR substitui o anterior.

## Estrutura mínima

1. Contexto
2. Decisão
3. Consequências positivas
4. Riscos e limitações
5. Alternativas consideradas
6. Relação com o Blueprint do SIO
